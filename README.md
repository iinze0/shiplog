# ShipLog

Turn a raw git log into a clean, human “what I shipped” post.

Paste the output of `git log --oneline` (or any commit list). Get a readable changelog with New / Fixed / Improved sections instead of technical commit messages.

## Why

Changelog generators spit “devspeak”. People building in public still rewrite everything by hand every week.

## Features

- Paste any git log
- Groups into New / Fixed / Improved / Other
- Cleans conventional commit prefixes
- Copy as Markdown

## Usage

Open `index.html` in a browser.
